# Rolex Live — PWA

Orologio analogico Rolex animato con lancette mobili, data, sincronizzazione Internet dell'ora e modalità offline. Fotografia senza piedistallo, icone PWA 192/512 e service worker inclusi.

## Attivare GitHub Pages una sola volta

1. Apri **Settings → Pages** nella repository `giorgiosacchi/rolex`.
2. In **Build and deployment**, imposta **Source: Deploy from a branch**.
3. In **Branch**, scegli **main** e **/(root)**, poi **Save**.

Una volta pubblicato il sito: https://giorgiosacchi.github.io/rolex/

Su Android, aprilo in Chrome e scegli **Installa app** (oppure menu ⋮ → **Installa app**).

I file necessari (`index.html`, `manifest.webmanifest`, `sw.js`, `icons/`, `assets/`) sono già presenti nella directory principale.
